# test.json 字段说明

一条记录按此顺序包含以下字段。

| 字段名 | 字段含义 | 数据类型 | 字段格式 |
|---|---|---|---|
| `frame` | 事件所在的视频帧号。同一帧可以有多条事件。 | 整数 | JSON 数字，不带小数。非负整数，按升序排列。与画面时间按 30 帧/秒对应。 |
| `player_code` | 行动球员的球衣号码。 | 字符串 | `unknown`，或 1–2 位十进制数字，无前导零。 |
| `player_id` | 行动球员的跟踪号。同一个人重新跟踪后号码会变。 | 字符串 | `unknown`，或无前导零的十进制数字。内容是数字时也写成字符串。 |
| `name_cn` | 球队与事件类型。 | 字符串 | `Team A` 或 `Team B` 与动作直接相连，中间无空格。动作为：`传球`、`停球（带球）`、`长传`、`抢断`、`射门`、`助攻`、`界外手抛球`。进球写 `Team AGoal`、`Team BGoal`。扑救写 `Team A_GKSave`。`角球` 不带队名。 |
| `receiver_code` | 关联球员的球衣号码，如接球人、被抢者。 | 字符串 | 与 `player_code` 相同：`unknown`，或 1–2 位球衣号。 |
| `receiver_id` | 关联球员的跟踪号。 | 字符串 | 与 `player_id` 相同：`unknown`，或数字字符串。 |
| `player_screen_xy` | 行动球员在该帧的画面坐标，单位是像素。 | 两个数字组成的数组 | `[x, y]`。两个元素都是 JSON 数字，可以带小数。`x` 向右，`y` 向下。位置未知时为 `[0.0, 0.0]`。 |
| `action_screen_time_period` | 该帧的画面时间。 | 字符串 | 固定 8 个字符，`MM:SS.cc`：两位分、两位秒、小数点、两位百分秒。 |
